# 📘 Atividade: Aplicativo de Tarefas com Interface Gráfica

## 🎯 Objetivo

Construir uma pequena aplicação visual em Python usando Tkinter para adicionar, remover e acompanhar tarefas diárias. Esta atividade ajuda os alunos a praticar lógica de programação, interação com interface gráfica e organização de código em classes e funções.

## 📝 Tarefas

### 🛠️ Criar a janela principal e os elementos da interface

#### Descrição
Crie uma janela principal com título e tamanho adequados, além de campos para inserir novas tarefas e uma lista para exibir as tarefas cadastradas.

#### Requisitos
O programa concluído deve:

- Importar a biblioteca `tkinter`
- Criar uma janela principal com título e tamanho apropriados
- Incluir um campo de entrada para escrever uma tarefa
- Incluir um botão para adicionar a tarefa
- Exibir as tarefas em uma lista visual

### 🛠️ Adicionar tarefas na lista

#### Descrição
Implemente a lógica para capturar o texto digitado pelo usuário e inserir a tarefa na interface.

#### Requisitos
O programa concluído deve:

- Ler o texto digitado no campo de entrada
- Validar que o campo não esteja vazio
- Adicionar a tarefa à lista visual
- Limpar o campo após a inserção
- Mostrar uma mensagem clara se o usuário tentar adicionar uma tarefa vazia

### 🛠️ Remover tarefas e atualizar o estado da aplicação

#### Descrição
Crie a funcionalidade para selecionar uma tarefa e removê-la da lista, além de dar feedback ao usuário sobre ações realizadas.

#### Requisitos
O programa concluído deve:

- Permitir selecionar uma tarefa na lista
- Incluir um botão para remover a tarefa selecionada
- Excluir a tarefa da interface após a ação
- Atualizar uma mensagem de status com o resultado da operação
- Ajustar o comportamento quando nenhuma tarefa estiver selecionada

### 🛠️ Melhorar a experiência do usuário com organização e clareza

#### Descrição
Adicione pequenos detalhes que deixam a aplicação mais útil e amigável, como limpar a lista, marcar tarefas concluídas ou reorganizar a lógica em funções.

#### Requisitos
O programa concluído deve:

- Organizar o código em funções ou uma classe principal
- Incluir uma opção para limpar a lista ou encerrar a aplicação
- Permitir feedback visual ao usuário após ações importantes
- Manter a interface simples, funcional e fácil de usar
